# Documentation

- `adr/` — architecture decision records. One file per decision that would be
  expensive to reverse. Write it when the decision is made, not afterwards.
- `research-log/` — dated entries: what was tried, what the numbers were, what
  it changed. Negative results belong here too; they are the ones that get
  forgotten and re-run.
- `model-cards/` — one per trained model: data, intended use, measured limits.
- `datasheets/` — one per dataset: how it was collected, labelled, split, and
  what is known to be wrong with it.

The design doc is `readme.md` in the repository root. The tracker is `plan.md`.
